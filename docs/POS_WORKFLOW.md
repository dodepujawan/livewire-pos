## Standard Keyboard Flow

Default sequence:

1. Focus Kode Barang
2. Enter → Cari Barang
3. Focus Qty
4. Enter → Tambah ke Cart
5. Focus kembali ke Kode Barang

Mouse should not be required for the common transaction flow.
